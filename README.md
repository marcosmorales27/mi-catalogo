# RetroGames - Catálogo de Videojuegos

Mini aplicación desarrollada en Angular.

# Requisitos

Tener instalado:

* Node.js
* npm
* Angular CLI

---

# Instalación

Entrar a la carpeta del proyecto
Instalar dependencias:

npm install

---
# Ejecutar el proyecto

Iniciar servidor de desarrollo:
bash
ng serve
o:
bash
npx ng serve

---
# Abrir en navegador

http://localhost:4200
